- Script generates a high-entropy random token (e.g. `crypto.randomBytes(32)`, base62/hex encoded), computes its hash, appends a new entry to `data/api_keys.yaml`.
- Prints the raw token to stdout exactly once with a warning that it can't be recovered later; never logs it anywhere else.
- Takes an optional `--label` so keys can be told apart in `list`/`revoke` (e.g. "laptop", "CI").
