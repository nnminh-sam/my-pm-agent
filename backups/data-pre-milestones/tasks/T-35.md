- `auth:list-keys` prints id, label, created date, last-used date, and revoked status for every stored key — never the hash or raw token.
- `auth:revoke-key -- <id>` sets `revoked_at` (soft delete, keeps history) rather than removing the entry.
- Revoking is idempotent (revoking an already-revoked key is a no-op, not an error).
