- Extend `isAuthorized` in `src/lib/auth.ts` (or add a sibling check) to also accept `Authorization: Bearer <key>` matched against a stored, non-revoked key's hash — independent of `PM_SECRET`, so agent keys can be issued/rotated without touching the web login secret.
- On each successful match, update that key's `last_used_at`.
- Missing header, malformed header, unknown key, and revoked key all fall through to the existing `401 { error: "unauthorized" }` response in `route.ts` — no new error shapes for MCP clients to special-case.
- `PM_SECRET` bearer keeps working during the transition (existing agents aren't broken mid-rollout).
