## Goal
A Gantt chart page in the web UI that draws tasks on a timeline, so the plan is visible at a glance.

## Scope
- New page (e.g. `/gantt`) linked from the top nav.
- Bars come from the scheduler output (`scheduleFor` → `ScheduledTask.start/end` and per-day `Block`s) — never recompute a schedule in the UI. Done tasks use their actual dates where available.
- Rows grouped Project → Feature → Task, with collapsible groups.
- Filters: project (multi-select), feature (multi-select, narrowed by selected projects), date range (from / to). Filters are kept in the URL query so views can be shared/bookmarked.
- Time units: **week, day, hour, minute** — switching rescales the timeline header and bar widths; gaps outside working hours are visible in hour/minute view.
- Visual cues: today marker, deadline markers, at-risk/late tasks highlighted, dependency arrows (nice-to-have), hover tooltip with id, title, estimate, start–end.
- Clicking a bar opens the task page (`/tasks/[id]`).
- Works in light/dark theme and scrolls horizontally on narrow screens.

## Out of scope
- Drag-to-reschedule or editing from the chart (the schedule is computed).
- Exporting to image/PDF.

## Acceptance criteria
- With no filters, all scheduled open tasks appear in scheduler order.
- Each filter narrows the rows correctly and survives a page reload.
- Switching week/day/hour/minute keeps the visible range centered and bars align with header ticks.
- Minute view stays responsive with the current task volume (virtualize or cap the range).
- Tests cover the pure mapping from schedule + filters + unit → bar positions.
