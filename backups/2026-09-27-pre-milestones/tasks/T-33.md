- Zod schema in `types.ts` for a stored key: `id`, `label`, `hash` (never the raw token), `created`, `last_used_at`, `revoked_at`.
- New store file `data/api_keys.yaml` (list of keys), read/written through `FileStore` like `settings.yaml` — no direct fs access.
- Hash with a fast keyed hash (HMAC-SHA256, not bcrypt — these are high-entropy random tokens, not passwords) so lookup by presented key is a cheap comparison.

**Done when:** the schema round-trips through `toMarkdown`/YAML parse/write helpers with no raw key ever persisted.
